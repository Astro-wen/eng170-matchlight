# Athlete photography

These 12 real profile portraits correspond to the finalists in the saved Paris
2024 women's individual 3m springboard final. They are **official profile
portraits, not photographs taken during that final**. Several were refreshed by
the source in 2025. They are not AI-generated.

## Identity and retrieval

Retrieved 14 October 2026 from publicly accessible World Aquatics athlete profile
pages. For each athlete:

1. Matched the historical result's `ResultId` (without the `R`) to the official
   athlete profile page ID.
2. Matched the profile's printed name and country to the historical record.
3. Used the image with the page's `athlete-header__profile--image` class and named
   `alt` text; its CDN URL contains the exact `ScoreboardPhoto` UUID in the
   official result record.
4. Visually checked all 12 downloaded portraits. Each file is an unmodified
   350 × 350 PNG served by the official public CDN, with a distinct athlete
   portrait and no placeholder.

Country codes in the application come from the real competition result; a
photograph does not determine nationality. Fictional demo participants have no
entry in this module and must keep a neutral avatar.

## Source and credit

World Aquatics publishes these assets. No separate photographer or explicit
open reuse license is stated on the athlete profile pages. The official site
reserves its rights; public availability is not an assertion that these images
are public domain. The prototype records the source and displays an official
profile credit. No ESPN or Getty news photography is included in this asset
module.

## UI integration

`getAthleteMedia(name)` accepts the result's surname-first name or the official
profile's given-name-first name, ignoring case and repeated whitespace. It
returns the local source, named alt text, short credit, and official profile URL.
Unknown names return `undefined`; consumers should render a neutral avatar.

Use the local image paths for stable rendering, and expose the returned source
URL/credit in the interface's photography credit area or athlete profile link.
